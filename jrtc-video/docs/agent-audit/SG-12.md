# SG-12 subscriber response compatibility — 2026-11-14

Branch: `codex/gateway-subscriber-compat`, based on the exact consumer pin
`87bbb9b79870724a91fc98f8711c55f5cb4519e2`. This narrowly supports the authorized
dedicated signalling gateway task; sibling plugins and service ownership are
unchanged. The earlier audit and its acceptance states remain historical.

Janus 1.1.2 retains inactive subscriber m-lines after their source disappears.
Its `janus_videoroom_subscriber_streams_summary` omits `feed_id` for those slots;
data m-lines can also use aggregate `source_ids`. SG-12 browser run
`Leydotpy/synq.js/actions/runs/42450937964` exposed a missing-feed validation
failure in a real Janus update. `SubscriberStreamInfo` now represents this shape
without fabricating a source identity. Active or unspecified-state audio/video
still require a positive, non-boolean feed ID; supplied invalid IDs stay invalid.
